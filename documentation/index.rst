aioengiebelgium
===============

Async Python client for the ENGIE Belgium consumer API. Requires Python >= 3.14.

.. warning::

   This library is unofficial and reverse-engineered. It is not endorsed by
   ENGIE, and it may break without notice whenever ENGIE changes their API.
